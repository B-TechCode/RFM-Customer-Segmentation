# RFM Customer Segmentation

##  Project Overview

RFM (Recency, Frequency, Monetary) Analysis is a customer segmentation technique used to understand customer purchasing behavior based on three key metrics:

- **Recency:** How recently a customer made a purchase.
- **Frequency:** How frequently a customer makes purchases.
- **Monetary:** How much money a customer has spent.

This project applies RFM analysis and K-Means clustering to the Online Retail II dataset to identify different customer groups and understand their purchasing patterns. These insights can help businesses develop targeted marketing strategies and improve customer engagement.

## Objectives

- Perform data cleaning and preprocessing.
- Calculate Recency, Frequency, and Monetary values for each customer.
- Assign RFM scores and classify customers into different segments.
- Apply K-Means clustering to identify customer groups.
- Visualize customer segments and purchasing behavior.
- Derive business insights from customer segmentation.

##  Dataset

**Dataset:** Online Retail II

The dataset contains transaction records from an online retail business.

**Dataset Source:** [Online Retail II - UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

Important attributes include:

| Column | Description |
|---|---|
| Invoice | Invoice number |
| StockCode | Product code |
| Description | Product name |
| Quantity | Quantity purchased |
| InvoiceDate | Transaction date and time |
| Price | Unit price |
| Customer ID | Customer identification number |
| Country | Customer's country |

##  Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Development Environment:** Jupyter Notebook

##  Project Workflow

### 1. Data Preprocessing

- Inspected the dataset and its structure.
- Identified and removed duplicate records.
- Handled missing Customer ID values.
- Converted Customer ID into string format.
- Removed transactions with non-positive quantities or prices.

### 2. RFM Table Creation

Calculated three customer-level metrics:

- **Recency:** Number of days since the customer's latest purchase.
- **Frequency:** Number of transactions made by the customer.
- **Monetary Value:** Total revenue generated by the customer.

Revenue was calculated using:

`Revenue = Price × Quantity`

### 3. RFM Scoring and Segmentation

- Used Pandas `qcut()` to assign scores from 1 to 5 for Recency, Frequency, and Monetary Value.
- Combined the three scores to calculate an overall RFM score.
- Classified customers into four segments:

| RFM Score | Customer Segment |
|---|---|
| 10–15 | Top Customers |
| 7–9 | Loyal Customers |
| 5–6 | Potential Customers |
| Below 5 | Lost Customers |

### 4. K-Means Clustering

- Selected Recency, Frequency, and Monetary Value as clustering features.
- Applied StandardScaler for feature scaling.
- Used the Elbow Method to examine the optimal number of clusters.
- Applied K-Means clustering to group customers.
- Visualized customer clusters using Seaborn pair plots.

##  Key Insights

The analysis identifies four customer segments:

- **Top Customers:** Customers with strong purchasing activity and spending.
- **Loyal Customers:** Customers who purchase regularly and can potentially become top customers.
- **Potential Customers:** Customers who may be encouraged to purchase more frequently.
- **Lost Customers:** Customers with low engagement who may need re-engagement strategies.

### Business Recommendations

- Offer exclusive products and loyalty rewards to Loyal Customers.
- Use personalized promotions to convert Potential Customers into Loyal Customers.
- Introduce win-back campaigns and special discounts to re-engage Lost Customers.
- Maintain customer relationships through targeted marketing strategies.
